# Aanchal portfolio

Static site. No build step.

## Structure
- index.html  Home
- about.html  About, skills, contact
- experience.html  Work and education
- projects/index.html  All projects
- projects/agriyukt.html, walksafe-ai.html, safetyiq.html  One page per featured project
- assets/css/style.css  All styles and colours (change the colours at the top)
- assets/js/main.js  Light and dark theme toggle
- assets/images/  Your photos and screenshots

## Before publishing
Search all files for these and replace them:
YOUR_GITHUB, YOUR_LINKEDIN, YOUR_EMAIL, YOUR_RESUME_LINK

## Host on GitHub Pages
1. Create a public repo named YOUR_USERNAME.github.io
2. Upload everything inside this folder (not the folder itself)
3. Settings, Pages, branch main, folder root, Save
4. Open https://YOUR_USERNAME.github.io
